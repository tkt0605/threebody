  - bash(git diff:*)

## 現在の状況
以下のシェルコマンドを実行し、現在のリポジトリの状態を正確に把握してください。

- ステージング済みの差分: !`git diff --cached`
- ワーキングツリーのステータス: !`git status`

## 指示
取得した内容を踏まえ、ユーザーに対して以下のルールを厳格に守って変更点を提示してください。

1. **変更タイプの分類**: 変更内容を「作成（新規ファイル）」「変更（修正ファイル）」の順に並べる。
2. **フォルダごとのグループ化**: 同一のディレクトリ（フォルダ）に属するファイルごとにグループ化して、視覚的にわかりやすく構造化する。
3. **ゼロベースの例外処理**: ステージング差分も未追跡の変更も何もない場合は、他の説明を一切省き、**「変更はなし」**とだけ出力する。

# トリアージラベル

各スキルは5つの正規トリアージロールで語る。このファイルはそれらのロールを、このリポジトリのIssueトラッカーで実際に使われているラベル文字列に対応付ける。

| mattpocock/skillsでのラベル | このトラッカーでのラベル | 意味 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | メンテナーがこのIssueを評価する必要がある |
| `needs-info` | `needs-info` | 報告者からの追加情報待ち |
| `ready-for-agent` | `ready-for-agent` | 仕様が完全に固まり、AFKエージェントに着手可能 |
| `ready-for-human` | `ready-for-human` | 人間による実装が必要 |
| `wontfix` | `wontfix` | 対応しない |

スキルがロールに言及したとき（例: 「AFK対応可能のトリアージラベルを付ける」）、この表に対応するラベル文字列を使う。

右列を、実際に使っている語彙に合わせて編集すること。

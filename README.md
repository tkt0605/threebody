# Three Body
### `Three Bodyは、マルチモーダルAI体験を探求するためのプロトタイプです。`

従来のチャットインターフェースは、テキストがベーシックな機能となっている。ユーザーはメッセージを通してAIとの双方向やり取りを実現している。
ThreeBodyはこれを根本から見直しました。数学の問題にある「三体問題」に由来とインスピレージョンを受け、サイドバーにある各機能
（ここでは、ノードという）を三角形に配置をして、その重心に音声チャット機能がデフォルトで配置されている。この１〜３つのNodeの設定内容を元に、
ユーザー個々人で自らAIをパーソナライズできる。

重要なポイントは、`ユーザーが行うAIとの会話形式はテキストストリームに限定されない。`という点です。視覚体験と感覚的なものを軸にユーザが使っていて楽しいと思えるように設計をしました。つまり、会話の流れによって、画像・動画が生成され、地図が探索可能になり、個人のセキュアホールの構築、ゲームがプレイ可能になるのです。

ThreeBodyは、視覚的なコミュニケーションとテキストによるコミュニケーションがシームレスに連携し、また自分自身に今必要なNodeを書くチャットごとに構築することで、真にマルチモーダルなチャットインターフェースを構築するために必要なアーキテクチャ、デザインパターン、およびユーザーエクスペリエンスの原則を示しています。
